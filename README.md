# Домашнее задание: Анонимный чат (Short Polling)

React-приложение, реализующее механику анонимного чата с сохранением сессии пользователя и автоматическим обновлением сообщений (Short Polling).

## Реализованный функционал

* **Анонимность и сессии:** При первом входе генерируется уникальный `userId` (через библиотеку `uuid`), который сохраняется в `localStorage`. Это позволяет сохранять идентичность пользователя при обновлении страницы.
* **Периодический опрос (Short Polling):** Реализован механизм автоматического запроса новых сообщений с сервера каждые 3 секунды через `setInterval` внутри хука `useEffect`. Для оптимизации трафика запрашиваются только новые сообщения (параметр `from`).
* **Умный UI:** * Свои сообщения (совпадение `userId`) отображаются справа в зеленых "пузырях".
  * Чужие сообщения отображаются слева в белых "пузырях".
  * Добавлен автоматический плавный скролл вниз при получении новых сообщений (`scrollIntoView`).
